## Notes

- **Order, not timestamps.** The software-GL render has a variable frame rate, so video
  time is not linear in wall-clock. Scoring the ORDER sidesteps this and uses the
  machine-exact command sequence as ground truth.
- **Distinct from VPT/MineRL.** Not frame-level inverse dynamics; a long-horizon,
  high-level, typed, ordered event-ledger reconstruction with a deterministic verifier.
- **Fresh render + occlusion-free.** A flat ground mosaic (no vertical occlusion) means
  every event is visible; blocks are 11 distinct solid types; fixed camera. Video is
  generated by us; GT is the bot's log — zero dataset overlap, no annotation error.
